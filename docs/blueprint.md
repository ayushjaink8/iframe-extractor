# **App Name**: IframeXtractor

## Core Features:

- HTML Upload & Extraction: Enable users to upload HTML files and extract all iframe `srcdoc` contents.
- Iframe Selection & Preview: Display extracted `srcdoc` content in a selectable list and preview the selected iframe content.
- Iframe Route Generation: Render extracted iframe content on dedicated routes (e.g., /iframe1, /iframe2).
- Drag and Drop Support: Allow users to drag and drop HTML files for upload.

## Style Guidelines:

- Primary color: Soft teal (#4DB6AC) for a calm and professional look.
- Secondary color: Light grey (#EEEEEE) for backgrounds and subtle contrasts.
- Accent: Orange (#FF8A65) for interactive elements and highlights.
- Use a clean, modern layout with adequate spacing and clear visual hierarchy.
- Use simple, outline-style icons for file operations and user actions.
- Subtle transitions and animations for feedback during file loading and iframe selection.
